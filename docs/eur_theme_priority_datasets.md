# EUR/D1 TOP800 theme: priority datasets

EUR has priority until **8 Nov 2026**: Delay-1 alphas in EUR on TOP800 earn **2x** (Python alphas **3x**). Every row on BRAIN's EUR D1 theme page also shows Theme Multiplier 1.3.

The list keeps datasets with value score 3 or more (under-used: fewer alphas, less production correlation) plus the AI / deep-learning sets, which Zacc wants first. Order: AI first, then value score, then fewest alphas. BRAIN's own recommended datasets for the theme (analyst4, analyst69, analyst14, model110 ...) are its most crowded ones (value score 1, thousands to 190,000 alphas): fine for learning, hard for originality.

## What page 2 added

- **Deep Learning Price Signal Dataset**: value score 5, 97% coverage, only 109 alphas. It is now second on the list, right after AI Equity Alpha Forecasts.
- **Three more value-5 sets**: Multi-Source Market Return Prediction and Multi Factor Market Return Predictions (143 alphas each; first check in Data Explorer whether the fields are per stock or one market-level number, because a market-level forecast is the same for every stock and ranks to nothing), and Multi-Domain Quantitative Factor Library (quant_factor_lib, 306 alphas).
- **News**: most of page 2 is News data. EUR/D1/news is a Pyramid cell (multiplier 1.3) with nothing in it yet, and News is a category not in the W43-W45 plan. One news alpha a week would start that cell; Significant Developments Data (64 alphas) and Conference call data (87) are the least used. BRAIN recommends SUBINDUSTRY neutralization for news.
- **Same name, different dataset**: Europe Analyst Estimate Daily Data, Insider Transaction Analytics, Nonlinear adaptive model and Fundamental Income and Dividend Model each appear twice with different coverage and alpha counts. They are different datasets: tell them apart by id. The page-2 Europe Analyst Estimate Daily Data has 93% coverage (vs 69%), so prefer it.

Risky but interesting: London Stock Sentiment Signals has the top value score (6) and only 11 alphas, but covers 16% of TOP2500 - expect thin long/short counts; ts_backfill helps.
